PRODUCT TRANSPARENCY

Privacy and data handling

CommonThread is a local hackathon build with account sign-in and private workspace records. Starter requests and catalog records are illustrative.

Information stored locally

The app stores account email, display name, password hash, hashed session identifiers, workspace name and market, request text, planning caps, kit briefs, restrictions, generated plans, itemized orders, support tickets, and payment status in SQLite at data/commonthread.sqlite, unless the operator sets another database path. Passwords are stored as salted scrypt hashes. Session cookies are HTTP-only and expire after seven days.

Request and support text is scoped to the signed-in workspace. The interface discourages names, exact addresses, health details, passwords, and payment credentials in free-text fields. This is a hackathon build, not a complete production identity or privacy program. Operators with filesystem access can access the database.

When Gemini is configured

For planning, the server sends the selected request details, kit brief, USD reference budget, restrictions, and available catalog information to Google's Gemini Interactions API with store: false. The plan is stored locally. For assistant questions, the server sends the question, workspace name, selected market and currency, and aggregate request/order counts; it does not send account email, order lines, or support tickets. Assistant conversations are not stored by this application. Without a Gemini key, deterministic local planning and a small product-support knowledge base run without sending these prompts to Google.

When PayPal sandbox is configured

Item names, quantities, checkout currency, prices, and order references are sent to PayPal sandbox. Sandbox captures use test funds, not real money. Without PayPal credentials, saving a local record sends no payment request. The checkout currency may differ from the community's local currency.

When social sign-in is configured

Google or PayPal sign-in sends the provider an authentication request and returns a provider subject, display name, and verified email for account access. The server requests only OpenID, profile, and email scopes and does not retain provider access tokens. PayPal identity sign-in is separate from checkout and does not grant access to bank details, balances, or payment credentials. The shared judge account is public and contains only isolated sample data.

Currency reference data

For non-USD estimates, the server requests the latest available daily USD reference rate from Frankfurter and stores the rate and date with an order. A rate lookup includes the requested currency code but no account or request details. This is not PayPal's final conversion quote; PayPal may apply its own conversion and fees.

Other services

The interface loads the Manrope font from Google Fonts. It does not include analytics or advertising trackers. A support request is stored in SQLite and is not emailed automatically. Gemini, PayPal, Frankfurter, and Google Fonts process relevant network requests under their own terms and privacy notices.

Scope

This page describes the current prototype behavior and is not a production privacy program. Do not use this build for real aid requests, sensitive personal information, or live payments.
